Running more than one branch?

TechDesk Enterprise can connect several shops to one HQ account, so you can see combined sales, inventory and activity across every branch.

1
Create a free HQ account below. You'll get a Business Key by email — this is what identifies your account.
2
Paste it into Settings → Connect to HQ on the computer you want to use as your head office.
3
Generate a Branch Code for each shop. Each branch manager pastes their code into their own Settings to link their data.

Already have a Business Key? Open Settings → Connect to HQ inside TechDesk Enterprise — no need to sign up again.
