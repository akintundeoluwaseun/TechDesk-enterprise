# TechDesk Solo source snapshot

This ZIP contains the TechDesk Solo source files restored in the current sandbox.

Important: the sandbox recovery restored only files touched during the previous session, not the complete original project tree. Therefore this is a partial recovery snapshot, not a complete runnable source archive. It includes the recovered Electron main/preload code and the recovered React application files, but missing untouched pages, components, package metadata, and configuration must be restored from the original project or repository.

The previously built installers remain available in the dedicated Google Drive release folder. To create a complete runnable source ZIP, supply the original TechDesk Solo project folder or repository export.
